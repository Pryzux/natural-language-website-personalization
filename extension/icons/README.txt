Extension Icons

The extension manifest references icon files (icon16.png, icon48.png, icon128.png)
but these files are not included in the repository.

Chrome will use default extension icons automatically when these files are missing.
This does not affect the functionality of the extension in any way.

If you want to add custom icons:
1. Create PNG files at 16x16, 48x48, and 128x128 pixels
2. Name them icon16.png, icon48.png, and icon128.png
3. Place them in this directory (extension/icons/)

The extension will automatically use them once added.

Recommended icon themes:
- Paint brush or magic wand (customization tool)
- AI/sparkle symbol (AI-powered)
- Color palette (styling/design)
- Gradient background with purple/blue colors (#667eea to #764ba2)
